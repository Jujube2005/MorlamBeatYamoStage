# MorlamBeatYamoStage

This project is a rhythm-based game created to study and implement fundamental game development systems using Godot.

It includes features such as real-time input detection, timing judgment (Perfect/Great/Good/OK/Miss), combo and scoring systems, and dynamic object spawning. The project emphasizes clean structure and modular design for scalability and further development.

This serves as a practical exercise in building interactive systems and improving programming skills in game development.

## Features
- 🎵 Rhythm-based gameplay
- 🎯 Timing judgment system
- 🔥 Combo & scoring system
- ⚡ Real-time input handling

## Built With
- Godot Engine 4
- GDScript
